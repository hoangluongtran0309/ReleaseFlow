# ReleaseFlow

ReleaseFlow turns merged pull requests, merge requests, and finished issues into
reviewed, audience-specific release notes.

The first release is being prepared. Development happens on the
[`develop`](https://github.com/hoangluongtran0309/ReleaseFlow/tree/develop) branch;
this branch receives each release once it is published.
